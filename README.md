## S L V Player

Transforme playlists de vídeo em cursos organizados. Importe uma playlist do YouTube, agrupe as aulas em módulos, acompanhe o progresso e faça anotações por minuto de vídeo.

![S L V Player: curso aberto com player, módulos e progresso](https://github.com/gblnovaes/slv-player-download/releases/download/v0.2.0/screenshot.png)

### Instalação

| Sistema | Arquivo | Como instalar |
| --- | --- | --- |
| Windows 10/11 (64 bits) | `SLV-Player-*.exe` | Execute o instalador. Se o SmartScreen avisar, clique em **Mais informações → Executar assim mesmo** (o instalador ainda não é assinado). |
| Linux (64 bits) | `SLV-Player-*.AppImage` | `chmod +x SLV-Player-*.AppImage` e depois execute o arquivo. |

### Como usar

1. Clique em **Importar playlist** (ou em **Conectar plataforma** na barra lateral) e cole o link de uma playlist pública do YouTube.
2. O app cria o curso com todas as aulas. Não é preciso chave de API.
3. Assista no player central. Use **Concluir aula** para marcar o progresso; o app lembra onde você parou.
4. Reorganize: arraste aulas, crie módulos em **Novo módulo**, renomeie (lápis) ou remova (lixeira). **Ordem original** mostra a ordem da playlist.
5. Escreva notas marcadas com o tempo atual em **Minhas notas** e ative as legendas pelo botão de legendas do player.
6. Alterne entre os temas **Escuro** e **Claro** no canto superior direito.

### Observações

- Hoje só o YouTube importa playlists. Vimeo, Twitch, Dailymotion e arquivos locais aparecem como "Em breve".
- Os dados ficam salvos no seu computador; nada é enviado a servidores do projeto.
- Se a importação falhar, a mensagem mostra o motivo; inclua-o ao reportar o problema.
